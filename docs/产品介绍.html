01

它解决的是这些很具体的小事

不讲"赋能""生态"，只讲你每天都在遇到的那几下卡顿。

找图

为了找一张参考图，翻了 6 个文件夹

素材散在下载、桌面、微信、网盘、移动硬盘里，最后靠"我记得是上周存的"乱翻。

重复

同一张图存了 3 份，改了一份忘了另外两份

没有库就没有"唯一副本"，改完也不知道哪份才是最新的。

预览

PSD、RAW、3D 文件全是白图标

只能靠文件名猜内容，打开一个要十几秒，翻十个就没了耐心。

批量

一百张图要改尺寸、加水印，只能一张张来

想批量又怕覆盖原图，做完发现改错了还退不回去。

记忆

只记得"蓝调、海边、逆光"，不记得文件名

文件名是 IMG_4821，文件夹叫"新建文件夹 (2)"，关键词搜不到。

交付

客户要看方案，只能压缩包发过去

对方解压后一堆散图，没有顺序、没有备注，也看不出你在讲什么。

02

八个方面的功能，按你干活儿的顺序排

下面每一条都已经装进安装包里，不是"规划中"。看的时候可以直接对照你自己的工作流。

收集 从哪儿来都行

素材进来的方式，决定了你愿不愿意真的用它。

  • 浏览器右键收藏：看到好图右键一下进库，不用先下载再导入。
  • 拖拽 / 粘贴：文件拖进窗口；截图直接 Ctrl+V。
  • 监听文件夹：指定几个文件夹，往里丢文件就自动入库。
  • ZIP 整包导入：别人发的素材包不用先解压再挑。
  • 10 个网络采集源：按关键词/网址批量抓，断了能接着采。
  • 手机网页上传：同一局域网下用手机浏览器传图，不用装 App。

重复文件自动跳过；大库重扫只处理新增部分。

整理 一个人也能建体系

不用一开始就想清楚分类，先收进来，再慢慢理。

  • 多层级文件夹 + 多资源库：不同项目各建一库，互不串图，随时切换。
  • 标签树 / 集合 / 书签 / 评分 / 颜色标记：一张图可同时属于多个分类，不复制文件。
  • 人物自动聚类：人像自动归堆，你再命名。
  • 地点与地图：带 GPS 的照片在地图上看；也能手动选国家/省/市。
  • 按天的时间线：左边点"某一天"，右边就是那天的素材。
  • 自定义字段：客户名、项目号、授权到期日，想记什么自己加。
  • 自动去重：内容指纹 + 视觉指纹，换个文件名也认得出来。

元数据可写进 XMP，换工具时标签和评分跟着文件走。

找 四种找法可叠加

"我知道我要哪张"这件事，应该在两秒内解决。

  • 中文子串搜索：不用分词，打两个字就命中标题、标签、说明的任意位置。
  • 语义搜索：直接描述画面（"海边 日落 逆光"），不用猜文件名。
  • 按颜色 / 按相似图：给一张参考图，找视觉上接近的。
  • 组合筛选：文件夹 + 标签 + 评分 + 格式 + 时间，条件叠加往下收窄。

2 万张的库实测：关键词 13 ms、按标签 12 ms——比眨一次眼快得多。

看 不用先打开软件

在库里直接预览，不用为"看一眼"启动 Photoshop。

  • 40+ 种 RAW：缩略图、EXIF、拍摄参数都有。
  • 11 种设计稿：PSD / AI / XD / Figma / Sketch 等直接出预览图。
  • 9 种 3D 模型、8 种视频、8 种音频。
  • PDF / Office / 字体文件：能预览，能筛。
  • EPUB 电子书：目录、正文、插图直接读，下次打开接着上次那一章，不用再装阅读器。
  • 瀑布流 / 大图 / 全屏灯箱：键盘上下左右就能逛完一整个库。

视频封面与时长自动提取，不用额外装解码包。

改 改坏了一步退回去

图库不该是"只读相册"，日常的修改应该就地完成。

  • 裁切 / 旋转 / 调色 / 擦除 / 放大 / 水印 / 相框 / 拼接。
  • 非破坏编辑：原图不动，改的是"操作记录"，随时还原。
  • 撤销 / 重做：200 步、累计 2 GB 的额度，误操作不心疼。
  • 批量处理：一次改一批，参数一致。
  • 自动构图：裁切时自动找画面主体（人脸只是加分项，不是唯一依据）。
  • 拼图逐格构图：三连海报、联系表、满版拼贴都能一格一格调焦点与缩放；海报文字可选字体、字号、颜色，参与拼图的是原图、质量最高到 100。

23 款水印 + 20 款相框，手机型号库近千个并按季更新。

用 跟系统长在一起

素材最终都要"拿出去用"，这一步不能靠导出。

  • 直接拖出去：拖进 Photoshop、Figma、微信、资源管理器都认。
  • 托盘常驻 + 全局热键：随时唤出，不用切窗口找。
  • Windows 动态壁纸：把库里的图直接设成桌面。
  • 局域网只读分享：给同事一个链接看图，密码 / 过期 / 禁止下载都能设。
  • 导出 HTML 画廊：一个文件发给客户，双击就能看，排版还是你排的。

文件自动关联、素材目录被外部改动会自动刷新。

自动化 能被脚本和 AI 调用

这一项是很多商业图库不给的：你的库应该能被程序用。

  • 本地接口：带口令与权限范围，脚本可以批量增删改查。
  • 11 个 MCP 工具：让 Claude 这类 AI 客户端直接读写你的素材库。
  • 插件沙箱：5 类权限位，插件能干什么写在明处，不能乱动你的文件。

适合批量整理、自动归档、接自己公司的内部流程。

数据 随时能带走

用得越久，越要在意"万一它没了怎么办"。

  • XMP 双向：标签、评分写进文件，换工具不丢。
  • CSV / JSON / HTML 导出：库里的信息永远不会被锁死。
  • 备份带校验：可以排程，坏了能查出来。
  • 回收站 + 库锁：删错了能捞回来；打开库要密码，防的是别人顺手翻你的库（注意：这不是硬盘加密）。

17 项数据操作有冒烟测试守着，改坏会被流水线拦下。

03

八个"别家没有或者做不顺手"的地方

这些是它真正区别于普通看图软件的地方——也是它值得单独装一个的理由。

01

中文子串搜索：打两个字就出

绝大多数图库的关键词搜索要求"完整词"或"分词"，你打"海边日"就搜不到"海边日落逆光"。这里用的是字符级索引，任何位置都能命中，中文尤其明显。

为什么少见：中文不分词还能快，需要对索引下很多额外功夫，多数产品直接放弃了。

02

记得画面就能找：本机语义检索

你已经忘了文件名、标签、甚至哪一年存的，但记得"那个蓝调的、有个人站在窗边"。用一句描述去找，2 万张库里 47 ms 出结果。

为什么少见：模型跑在你自己的机器上，不上传图片，也不消耗云端额度。

03

拖出去就能用：跟设计软件直连

选中素材直接拖到 Photoshop 画布、Figma 里，落地就是一张图，不用先"导出到桌面"再拖一次。

为什么少见：网页版产品结构上做不到这一点；能做到的桌面产品通常也懒得多做。

04

把库变成 Windows 动态壁纸

把某个文件夹里的图挂在桌面上轮播，还能设间隔与顺序。做设计、做内容的人会明显感到"素材活着"。

为什么少见：需要绕到系统桌面层去画，属于典型的"能用但麻烦"的功能。

05

不上云，也能给同事看图

局域网只读分享：生成一个链接，同一网络里的人用浏览器就能翻你的选图集，带密码、可设过期、可禁止下载。

为什么少见：多数产品把分享做成了云服务的入口，本地产品往往干脆不做。

06

改图不毁原图：操作记录 + 双栈撤销

裁切、调色、水印都是"记一笔"，原文件始终是原始字节；不满意的可以一路撤回，也能重做。

为什么少见：真做非破坏要改整个存储模型，很多产品只是"自动备份一份再覆盖"。

07

让你的 AI 助手直接读你的素材库

内置 11 个 MCP 工具，AI 客户端可以按你的指令检索、打标签、归档——不是聊天，是真动手。

为什么少见：这一步等于把自己的数据接口开放出来，多数商业产品不愿意。

08

两万张的库，翻起来还是顺的

滚动不是"一次加载全部"：分页用键集游标，索引走 SQLite 全文索引，缩略图带缓存。列表 7 ms、深页 11 ms。

为什么少见：大多数同类产品在两万张这个量级就开始转圈了。

04

快不快，看这几个数字就够了

全部是实测（Windows、2 万张素材的库），不是理论值。数字越小越好。

你会在意的场景实测换算成体感
导入 1 万个文件6,154 行/秒建库是"倒进去等一会儿"，不是等一整晚
打开素材列表7 ms点开就出，看不到转圈

05

三步就能用起来

不需要先读手册，也不需要整理好素材才能开始——它的设计前提就是"先乱着收，之后再理"。

1

装

从发布页下载 Windows 安装包，双击安装。首次运行如果弹出"未知发布者"，点"更多信息 → 仍要运行"即可。

2

建库

选一个空文件夹当素材库，建议放在空间大的本地硬盘，别放在网盘同步目录里——同步软件会让库反复重扫。

3

拖进来

把文件或整个文件夹拖进窗口，或者让它监听你的下载文件夹。等缩略图跑完，就能搜、能筛、能拖出去用了。

几个能省时间的小知识
  • 空格快速预览，不用双击打开；Ctrl+F 搜索，Ctrl+Z 撤销（可退 200 步）。
  • 先让缩略图跑完，再开 AI 分析，两层队列分开跑不会抢 CPU。
  • 内置 173 条新手教程，第一次打开会自动引导；不想看可以随时关掉。
  • 库锁只拦"打开这个库"，不加密硬盘文件——把它当门禁，别当保险箱。
06

它适合谁，不适合谁

一段话判断清楚，比看十屏截图有用。

用起来会很顺手

  • 一个人、一台 Windows 电脑做设计 / 摄影 / 内容。
  • 素材几万到几十万张，主要在本地硬盘或移动硬盘。
  • 需要批量整理、批处理、打包交付。
  • 想让脚本或 AI 客户端直接用上自己的素材库。
  • 在意"素材不被上传、格式不被绑架"。

典型用户：接私单的设计师、做自媒体的剪辑、需要管理参考图库的摄影爱好者。

现在真的不合适

  • 团队多人共用一套素材，需要权限与审批。
  • 主力机是 mac 或 Linux。
  • 需要在手机上随时随地看库、要云端自动同步。
  • 需要英文界面给海外同事用。
  • 开箱就要管百万级素材。

这五条不是"以后也能凑合"，是现阶段确实做不到——它们都写在下一节的"不足"里。

07

先说清楚它哪里还不够好

一份只讲优点的介绍没什么用。以下是它目前真实的短板，以及为什么会这样。

七个已知短板

  • 只有 Windows。mac / Linux 有构建脚本，但没做过真机验收，所以不对外宣称支持。
  • 没有云同步，没有手机 App。最接近的替代是局域网只读分享——同一网络里能看图，出了网络就不行。
  • 没有多人协作。没有账号体系、成员权限、审批流；替代方式是导出包 + 只读链接。
  • 只有中文界面。没有翻译层，界面文案直接写在组件里。
  • 2 万张实测良好，百万级没验收。时间线、清单、人物与图库主网格都已窗口化渲染，布局计算也改成了增量追加——滚动不再随库变大而变慢；但百万级仍是目标而非承诺。
  • 第一次导入并开启 AI 会很慢。模型在你本机 CPU 上跑，首次还要下载模型文件；白天来不及算的语义与人脸索引可以交给「夜间批处理」在闲置时段补，但第一晚仍要等。
  • 安装包偏大，且没有代码签名。v1.2.16 已裁掉约 200MB 用不上的跨平台推理库，但整体仍偏大；首次运行会被 Windows SmartScreen 拦一下，需要手动放行。
为什么会有这些短板？ 这是一个一个人做的项目：没有服务器预算，也没有第二个人的时间。 云同步与多人协作不是"写不出来"，而是做出来之后每个月都要为存储、带宽、备份和故障负责—— 那是一笔持续支出，不是一个版本的功能。所以它们被排成了远期目标，而不是宣传语。

这四项的顺序（先做不花钱的，再按收入决定云做到哪一档）：

远期目标现在目标值兑现顺序
多语言界面590第一步：文案抽成词条并冻结，不花钱、不依赖云
跨平台（mac 优先）2085第二步：真机冒烟 → 安装包 → 平台差异清单；Linux 顺延
云与多端1580第三步：只读多端 → 账号与增量同步 → 冲突合并
协作与社区2060第四步：批注 → 成员权限 → 审批流（插件市场不承诺）

把这四项也算进评分，17 项的成绩是 71.2，在 8 款产品里排第 3（单机场景是第 1）。 四项都做到目标值后是 87.1。这些数字与算法都写在 完整评测报告里，可以逐项核对。

它可能正好适合你，也可能完全不适合

"适合"那栏你点头超过三条，就值得装一个试试——素材始终在你自己的硬盘上， 卸载软件也不会带走或损坏你的文件。 "不适合"那栏你中了任何一条，就别勉强：评测里另外 7 款产品各自的适用场景也一并列了。
