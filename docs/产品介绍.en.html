01

It solves these very concrete, everyday annoyances

No talk of "empowerment" or "ecosystems"—just the little stalls you hit every day.

Find

You dug through six folders to find one reference image

Assets are scattered across Downloads, the desktop, WeChat, cloud drives, and external disks, so in the end you rummage around thinking "I'm sure I saved it last week."

Duplicates

The same image exists in three copies; you edit one and forget the other two

Without a library there's no single copy of record, and after an edit you can't tell which file is current.

Preview

PSDs, RAWs, and 3D files all show up as blank icons

You can only guess the contents from the file name; opening one takes a dozen seconds, and after ten you've lost patience.

Batch

A hundred images need resizing and watermarking—one at a time

Batch work risks overwriting the originals, and if you get it wrong there's no way to roll back.

Memory

You remember "blue hour, seaside, backlit"—but not the file name

The file is IMG_4821 and the folder is "New folder (2)"; keyword search finds nothing.

Delivery

A client wants to see the proposal, so you send a ZIP

They unzip a pile of loose images with no order, no notes, and no clue what you're presenting.

02

Eight areas of features, ordered the way you actually work

Every item below already ships in the installer—none is "planned." As you read, compare it against your own workflow.

Collect from anywhere

How assets get in decides whether you'll really use it.

  • Right-click to save in the browser: right-click a good image and it's in the library—no downloading first, then importing.
  • Drag / paste: drag files into the window; press Ctrl+V to add a screenshot.
  • Watched folders: point it at a few folders and anything dropped in is added automatically.
  • ZIP import: no need to unzip a shared asset pack before picking through it.
  • 10 web capture sources: batch-grab by keyword or URL, and resume after an interruption.
  • Phone upload via web page: send images from a phone browser on the same LAN, no app required.
  • Inbox: New images from web capture, upload, paste and phone upload are marked "to sort" first; review them in the sidebar before filing. Turn it off in Settings if you don't want it.

Duplicate files are skipped automatically; rescanning a large library only processes what's new.

Organize build a system on your own

You don't have to work out the categories up front—bring things in first, sort them later.

  • Nested folders plus multiple libraries: one library per project, no images bleeding between them, switch anytime.
  • Tag tree / collections / bookmarks / ratings / color labels: an image can belong to several categories at once, with no file copies.
  • Automatic face clustering: portraits are grouped for you; you name the groups.
  • Places and map: photos with GPS are shown on a map; you can also pick country/province/city manually.
  • Day-by-day timeline: click a day on the left and that day's assets appear on the right.
  • Custom fields: client name, project number, license expiry—add whatever you need to track.
  • Automatic deduplication: content hashes plus visual hashes, so even renamed files are recognized.

Metadata can be written into XMP, so tags and ratings travel with the file if you switch tools.

Find four search methods that stack

"I know which image I want" should take two seconds.

  • Substring search, Chinese included: no word segmentation—type two characters and match anywhere in titles, tags, or descriptions.
  • Semantic search: describe the scene directly ("seaside sunset backlit") instead of guessing the file name.
  • By color / by similar image: give it a reference image and find visually close matches.
  • Combined filters: folder + tag + rating + format + date, stacked to narrow things down.

Measured on a 20,000-image library: 13 ms for keyword, 12 ms by tag—far quicker than a blink.

View without launching another app

Preview right inside the library; don't fire up Photoshop just to take a look.

  • 40+ RAW formats: thumbnails, EXIF, and shooting parameters included.
  • 11 design formats: previews rendered directly for PSD / AI / XD / Figma / Sketch and more.
  • 9 3D model formats, 8 video formats, 8 audio formats.
  • PDF / Office / font files: preview and filter.
  • EPUB ebooks: read the table of contents, the text, and illustrations right here, and pick up at the same chapter next time—no separate reader needed.
  • Masonry / large view / fullscreen lightbox: browse an entire library with the arrow keys.

Video covers and durations are extracted automatically—no extra codec pack to install.

Edit one step back when you break something

A library shouldn't be a read-only album; everyday edits should happen in place.

  • Crop / rotate / color adjust / erase / upscale / watermark / frame / collage.
  • Non-destructive editing: the original is untouched; what you change is the operation log, which you can revert anytime.
  • Undo / redo: 200 steps and 2 GB of history, so mistakes don't hurt.
  • Batch processing: change a whole batch at once with consistent parameters.
  • Auto composition: cropping finds the subject automatically (faces are a bonus signal, not the only criterion).
  • Cell-by-cell collage composition: three-panel posters, contact sheets, and full-bleed collages can each be tuned cell by cell for focus and zoom; poster text supports font, size, and color, and collages use the original images at quality up to 100.

23 watermarks and 20 frames, plus a phone-model library of nearly a thousand entries refreshed quarterly.

Use woven into the system

Assets always end up being taken out and used—that step shouldn't require exporting.

  • Drag straight out: drop into Photoshop, Figma, WeChat, or File Explorer and it works.
  • Tray resident + global hotkey: summon it anytime without hunting for the window.
  • Windows live wallpaper: set images from your library as the desktop directly.
  • Read-only LAN sharing: give a colleague a link to view images, with options for a password, expiry, and blocking downloads.
  • Infinite canvas: Drag assets onto an endless board, add notes, shapes and link cards, then export the reference board as PNG / PDF.
  • Export an HTML gallery: send clients a single file that opens on double-click, with your own layout intact.

File associations are set up automatically, and asset folders changed outside the app refresh automatically.

Automate callable by scripts and AI

This is something many commercial libraries won't give you: your library should be usable by programs.

  • Local API: token-protected with permission scopes, so scripts can batch create, read, update, and delete.
  • 11 MCP tools: let AI clients like Claude read and write your asset library directly.
  • Plugin sandbox: five permission classes—what a plugin can do is stated plainly, and it can't rummage through your files.

Good for bulk organizing, automatic archiving, and plugging into your company's internal workflows.

Data yours to take anytime

The longer you use it, the more you should care about "what if it's gone someday."

  • Two-way XMP: tags and ratings are written into the files and survive a change of tools.
  • CSV / JSON / HTML export: your library's information is never locked in.
  • Metadata CSV round-trip: Export, edit titles, ratings, tags and color labels in Excel, then write them back by id or path — no clicking through items one by one.
  • Verified backups: schedulable, and corruption can be detected.
  • Recycle bin + library lock: deleted items can be recovered, and opening a library can require a password—it stops someone casually browsing your library (note: this is not disk encryption).

17 data operations are guarded by smoke tests, so breakage gets caught by the pipeline.

03

Eight things other products don't have, or don't do well

These are what really set it apart from an ordinary image viewer—and why it's worth installing on its own.

01

Chinese substring search: type two characters and it's there

Keyword search in most libraries requires complete words or word segmentation; type "seaside su" and "seaside sunset backlit" won't be found. This uses a character-level index that matches at any position, which matters most for Chinese.

Why it's rare: staying fast without word segmentation for Chinese takes a lot of extra work on the index, and most products simply give up on it.

02

Find it by what you remember seeing: on-device semantic search

You've forgotten the file name, the tags, even the year, but you remember "that blue-toned one, someone standing by a window." Search with a single description and get results in 47 ms across a 20,000-image library.

Why it's rare: the model runs on your own machine—no image uploads, and no cloud quota burned.

03

Drag it out ready to use: a direct line to design software

Select an asset and drag it onto a Photoshop canvas or into Figma; it lands as an image. No "export to the desktop, then drag it again."

Why it's rare: browser-based products structurally can't do this, and desktop products that could usually don't bother.

04

Turn your library into a Windows live wallpaper

Rotate images from a chosen folder on your desktop, with configurable interval and order. Designers and content creators clearly feel their assets come alive.

Why it's rare: it means drawing into the system's desktop layer—a classic "works, but is a pain" feature.

05

Show colleagues your images without the cloud

Read-only LAN sharing: generate a link and anyone on the same network can browse your selection in a browser, with a password, an optional expiry, and downloads that can be blocked.

Why it's rare: most products turn sharing into a doorway to their cloud service, and local-first products often skip it entirely.

06

Edit images without destroying originals: operation log + dual-stack undo

Crops, color adjustments, and watermarks are all "recorded entries"; the original file stays byte-for-byte intact. If you don't like the result, undo all the way back—and redo again.

Why it's rare: true non-destructive editing means changing the whole storage model, and many products just "auto-back up a copy, then overwrite."

07

Let your AI assistant read your asset library directly

11 built-in MCP tools let AI clients search, tag, and archive on your instructions—not just chat about it, but actually do it.

Why it's rare: it amounts to opening up your own data interface, which most commercial products aren't willing to do.

08

A 20,000-image library that still scrolls smoothly

Scrolling isn't "load everything at once": pages use keyset cursors, the index uses SQLite full-text, and thumbnails are cached. 7 ms for the list, 11 ms for deep pages.

Why it's rare: most similar products start spinning at the 20,000-image mark.

05

Up and running in three steps

No manual to read first, and no need to organize your assets before starting—its design premise is "collect it messy first, sort it later."

1

Install

Download the Windows installer from the release page and double-click to install. If Windows shows "Unknown publisher" on first run, click "More info → Run anyway."

2

Create a library

Pick an empty folder as your asset library. A local disk with plenty of space is recommended; avoid cloud-sync folders—sync software makes the library rescan over and over.

3

Drag things in

Drag files or whole folders into the window, or let it watch your Downloads folder. Once thumbnails finish, you can search, filter, and drag assets out.

A few time-saving tips
  • Space for a quick preview without double-clicking; Ctrl+F to search, Ctrl+Z to undo (up to 200 steps).
  • Let thumbnails finish before starting AI analysis; the two queues run separately so they don't fight over the CPU.
  • 173 built-in onboarding tutorials; the first launch guides you automatically, and you can turn them off anytime.
  • The library lock only guards "opening this library"; it doesn't encrypt files on disk—treat it as a door badge, not a safe.
06

Who it suits, and who it doesn't

One paragraph to decide is more useful than ten screenshots.

It will feel natural if

  • You do design / photography / content work solo on one Windows PC.
  • You have tens of thousands to hundreds of thousands of assets, mostly on local or external disks.
  • You need bulk organizing, batch processing, and packaged delivery.
  • You want scripts or AI clients to work directly with your asset library.
  • You care about assets not being uploaded and formats not being held hostage.

Typical users: freelance designers, editors running their own channels, and photography enthusiasts who manage a reference library.

It genuinely doesn't fit yet if

  • A team shares one asset collection and needs permissions and approvals.
  • Your main machine is a mac or Linux.
  • You need to browse the library from a phone anywhere, or want automatic cloud sync.
  • You need an English interface for overseas colleagues.
  • You need to manage a million-scale library out of the box.

These five aren't "we'll make do for now" cases—they genuinely aren't possible at this stage, and all are listed under "Limitations" in the next section.

07

Let's be clear first about where it still falls short

An introduction that only lists strengths isn't much use. Here are its real current weak spots, and why they exist.

Seven known weak spots

  • Windows only. There are build scripts for mac / Linux, but no real-device validation, so support isn't claimed.
  • No cloud sync, no mobile app. The closest substitute is read-only LAN sharing—view images on the same network, but not beyond it.
  • No multi-person collaboration. No accounts, member permissions, or approval flows; the workaround is an export package plus read-only links.
  • The English interface still has blind spots.The interface, tutorials, and docs are bilingual, but configuration display names (AI provider / model / capture source) are still in Chinese.
  • Validated at 20,000 images; million-scale is untested. The timeline, list, people view, and main library grid all render windowed, and layout calculation now appends incrementally—scrolling no longer slows as the library grows; but a million assets is a target, not a promise.
  • The first import with AI enabled is slow. The model runs on your local CPU, and the model files must be downloaded the first time; semantic and face indexing that can't finish during the day can be handled by "overnight batch processing" during idle hours, but the first night still means waiting.
  • The installer is large and has no code signing. v1.2.16 trimmed about 200MB of unused cross-platform inference libraries, but it's still large overall; the first run gets flagged by Windows SmartScreen and needs manual approval.
Why do these gaps exist? This is a one-person project: there's no server budget and no second person's time. Cloud sync and multi-person collaboration aren't "impossible to write"—but once built, you'd be on the hook every month for storage, bandwidth, backups, and outages— that's an ongoing expense, not a feature in a release. So they're scheduled as long-term goals, not marketing lines.
