2026-11-06 第五轮：对照总表逐条复核（修掉假阳性 / 真实 bug，并列出仍未达标项）

本轮不再堆新功能，而是拿 TASKS 的 check 验收字段逐条对照代码：前面四轮默认勾选了 38 条，其中若干条 「做了改动但没达到验收标准」，甚至藏了运行时 bug。以下把真正修掉的与仍未达标的分开列清楚 —— 勾选项里 kind=partial 的条目仍属「部分修」，不等于关闭。

  • T-22 视频导出挂起（真 bug）：recordClip() 的超时 watchdog 只调 rec.stop()，外层 Promise 永不结算，编码跳转不推进时导出永久卡住；同时补上 finished.catch(()=>{}) 防止无数据分支变成未处理拒绝。现在超时走同一个幂等 stop()。另外落库的 trimStart/trimEnd 以前只影响导出、常规播放当它不存在；MediaViewer 现在在 onLoadedMetadata 跳到起点、onTimeUpdate 到终点暂停，并在工具栏显示已保存区间。
  • T-23 只读令牌不只读（安全 bug）：apiAuth 以前只判断「令牌有效」就放行，只声明 read 的附加令牌可以绕过 /api/v1 的 403，直接 PUT 主 /api/* 写接口。现在主 API 也校验 scoped 令牌的 write scope，返回 403 / SCOPE_DENIED；主令牌与浏览器同源请求不受影响。
  • T-29 静音时频谱仍跳：音量归零放在 analyser 之后的 gain 上，analyser 照常有数据；现在 mute 时直接把频谱数据清零并给桌面层提示，符合「静音即静止」。
  • T-33 主题包注入与还原不全：author / fontFamily 以前只截断不过滤，而 --ui-font 会被 setProperty 直接写入 DOM；现在前后端同用一套白名单正则，分号/花括号/url()/尖括号一律剔除。壁纸设置白名单从「只有 wallpaperMode + 9 个 live 子键」扩到 wallpaperFill / screensaver / autoWallpaper 子集与 19 个 live 行为键，仍明确排除本机路径、可信目录、allowLocalUrl、凭据与运行态游标。
