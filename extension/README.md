# 图库采集助手（Chrome 扩展）

把网页上的图片一键存进本地图库。**纯本地**：扩展只把图片地址/截图 POST 到 `http://127.0.0.1:<port>/api/extension/ingest`，由桌面端负责下载与入库。

端口不写死：开发模式是 3001，桌面版由 Electron 选随机端口；扩展启动时探测 `3001-3012` 的 `/api/health`，命中的端口会缓存到 `chrome.storage.local`。

## 安装（开发者模式）

1. 打开 Chrome → `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本目录（`extension/`）

## 用法

- **单张**：在图片上右键 → 「采集这张图片到图库」
- **拖拽（与 Eagle 插件一致）**：拖住网页里的图片 / 从别的标签页拖图 / 从资源管理器拖本地图片文件，
  屏幕正中会浮出圆形「松手存入图库」投放点，丢上去即入库。只拦截丢在投放点上的拖放，
  页面自己的上传区、编辑器不受影响；图片被站点跨域保护取不到内容时会提示改用右键采集。
- **支持的图源**：`<img>`（http/https、`blob:`、`data:`）、`<canvas>` 渲染的图（AI 出图站常见）、
  带 `background-image` 的元素、拖拽数据里的 `text/uri-list` / `text/html` / `DownloadURL`、本地文件。
- **支持的格式**：JPG / PNG / WebP / GIF / AVIF / TIFF。拖进来的图**不再套采集器的质量门槛**
  （低于 30KB 或短边不足 800px 以前会被丢掉，现在照收——那是给爬虫批量抓图定的闸）。
- **下载方式**：先在浏览器里以你的身份取字节（带站点 Cookie，`<all_urls>` 权限），
  取不到才交给桌面端带 Referer 下载，所以登录态 / 防盗链站点的图也能存。
- **失败会说明原因**：格式不支持（avif）、分辨率太低、下载失败（HTTP 403）等直接显示在提示条上。
- **整页**：页面空白处右键 → 「采集本页所有图片到图库」（自动过滤宽高 < 400px 的小图，最多 30 张）
- **截图**：点扩展图标 → 「截取可见区域」
- **整页截图**：点扩展图标 → 「整页截图存图库」，或页面空白处右键 → 「整页截图存图库」。
  逐屏滚动截取后在扩展后台拼成一张长图入库，自动打上「整页截图」标签。
  上限 24 屏 / 16000px（超出会截断并在通知里说明）；截图期间请不要切换标签页，
  固定定位的导航条会在每屏重复出现（这是不弹调试黄条的代价）。
  超长页会自动降采样（画布像素上限 40MP），PNG 超过 22MB 时改存 JPEG，
  避免被本地服务 50MB 的请求体上限挡掉；页面开了 `scroll-behavior: smooth` 也能截准。
- 弹窗里可填**关键词**与**标签**，留空则默认用页面标题

## 注意

- 桌面端需处于运行状态（扩展会自动探测端口）
- 下载时会自动带上页面来源（Referer），对有防盗链的站点有效
- 接口仅监听 127.0.0.1，不对外暴露
- **扩展 ID 已固定**：`manifest.json` 里加了 `key`，本扩展的 ID 恒为
  `olckdffcmfpciekkkdekckpgphacfnfl`，服务端只对这个 ID 的 `Origin` 免令牌。
  如果你之前加载过旧版本，请先在 `chrome://extensions` 移除再从 `extension/` 重新加载，
  否则旧 ID 调用采集接口会收到 401（以前是「任何扩展都放行」，等于图库对本机所有扩展开放）。
- 需要换 ID（例如自己重新签名）时，同步改 `manifest.json` 的 `key`、
  `server/config.js` 的 `EXTENSION_ORIGINS` 默认值，或设环境变量 `TUKU_EXTENSION_ORIGINS`
